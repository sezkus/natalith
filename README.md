# NATALITH — support and legal pages

The support page, privacy policy and terms of use for the NATALITH iOS app, published
with GitHub Pages at <https://sezkus.github.io/natalith/>.

This repository exists only to host those three pages. GitHub Pages does not serve from
a private repository on the free plan, and the app's own repository is private — its
source includes the written guide that Full Access sells.

**These files are copies.** The originals live in the app repository under `docs/`, where
they are versioned alongside the app they describe: a privacy policy has to change when
the app does. Publish updates with `docs/publish_site.sh` from that repository rather
than editing here, or the two will drift and the wrong one will be the one people read.
